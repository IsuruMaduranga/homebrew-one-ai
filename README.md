# One AI Homebrew tap

Formulas for [One AI](https://github.com/IsuruMaduranga) tools.

```bash
brew install isurumaduranga/one-ai/one-code
```

| Formula | What it installs |
|---|---|
| `one-code` | [One Code](https://github.com/IsuruMaduranga/one-code) — the Claude Code experience on any model (`one-code` command) |
